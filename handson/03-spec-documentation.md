# Q2: 仕様を整理し、ドキュメント化する

**Time: 15 min**

## ゴール

仕様書と実装を比較し、確認できた事実、差分候補、判断が必要な点を分けて短い仕様メモにします。

## 1. 仕様書と実装を比較する

Chat Viewに`docs/app-spec.md`と`app.js`を追加し、次を依頼します。

```text
#file:docs/app-spec.md
#file:app.js

仕様書と実装を比較してください。
検索対象、ステータス表記、ソート、表示項目、期限切れ表示について、
「仕様書の記述（行番号付き）」「実装の根拠（ファイル名、関数名、行番号付き）」
「差分または要確認事項」の3列で整理してください。
internalMemoの具体値は引用・要約・出力せず、項目名と扱いだけを確認してください。
まだファイルは変更せず、実装から確認できないことは推測せず「要確認」としてください。
```

## 2. 差分候補を自分で確認する

回答に含まれる行を、仕様書、`app.js`、`data.js`、画面で確認します。

- [ ] 回答に示された行番号を実際に開き、記述が一致することを確認した
- [ ] 一覧の表示形式を確認した
- [ ] 検索対象の項目を確認した
- [ ] ステータスの表示文言を確認した
- [ ] 選択できる並び順を確認した
- [ ] 仕様書にある項目がデータと画面に存在するか確認した

> [!IMPORTANT]
> 仕様書と実装が違っても、どちらが正しいかは自動的に決まりません。修正前に、期待する動作をプロダクトオーナーや担当者へ確認します。

## 完了条件

- [ ] 仕様と実装の差分候補を3つ以上確認した
- [ ] 事実と未確定事項を分けた
