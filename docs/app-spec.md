# Support Ticket Dashboard 仕様書

## アプリの目的

Support Ticket Dashboard は、顧客から届いた問い合わせチケットを一覧で確認するためのアプリです。サポート担当者が、対応状況や優先度、期限を確認し、対応が必要なチケットを見つけやすくすることを目的とします。

Workshopでは結果を再現できるよう、日付判定の基準日を **2026-07-22** に固定します。チケットと社内メモはすべて架空の研修データです。

## 画面構成

画面は次の要素で構成します。

1. **ヘッダー**: アプリ名を表示します。
2. **検索欄**: キーワードを入力してチケットを検索します。
3. **ステータス絞り込み**: ステータスを選んで表示するチケットを絞り込みます。
4. **ソート選択**: チケットの並び順を選びます。
5. **チケット一覧**: 条件に合うチケットをカード形式で表示します。

## チケット項目

チケット一覧には次の項目を表示します。

| 項目 | 内容 |
| --- | --- |
| ID | チケットを識別する番号 |
| タイトル | 問い合わせの件名 |
| 顧客名 | 問い合わせを行った顧客の名前 |
| ステータス | 対応状況（未対応、対応中、解決済み） |
| 優先度 | 対応の優先度（高、中、低） |
| 期限 | 対応を完了する日 |
| 担当者 | チケットを担当する人の名前 |

`channel`、`slaHours`、`customerTier`、`internalMemo` は補助データです。`internalMemo` は社内確認用であり、画面に表示せず、検索対象にも含めません。

## 検索仕様

- 検索欄に入力した文字を、ID、タイトル、顧客名、担当者から検索します。
- 入力した文字を一部に含むチケットを表示します。
- 英字の大文字と小文字は区別しません。
- 検索欄が空の場合は、すべてのチケットを表示します。
- ステータス絞り込みを選んでいる場合は、両方の条件に合うチケットだけを表示します。

## ステータス絞り込み仕様

- 「すべて」「未対応」「対応中」「解決済み」から選択できます。
- 「すべて」を選ぶと、ステータスに関係なくチケットを表示します。
- それ以外を選ぶと、選択したステータスと一致するチケットだけを表示します。

## ソート仕様

- 「期限が近い順」と「優先度が高い順」を選択できます。
- 「期限が近い順」では、期限の日付が早いチケットから表示します。
- 「優先度が高い順」では、各チケットの優先度スコアが高いものから表示します。
- 優先度スコアは、優先度、期限切れ、期限までの日数をもとに決まります。
- 優先度スコアの詳細な計算規則は、プロダクトオーナーへの確認が必要です。
- 同じ順位になった場合の並び順は指定しません。

## 期限切れ表示仕様

- 現在の日付が期限を過ぎており、ステータスが「解決済み」ではないチケットを期限切れとします。
- 期限切れのチケットは、一覧の背景を赤くして目立たせます。
- 「解決済み」のチケットは、期限を過ぎていても期限切れ表示にしません。

## 受講者が確認すべき観点

仕様書とアプリを見比べるときは、次の点を確認してください。

- チケット一覧に必要な項目が表示されているか。
- 検索対象が仕様書と一致しているか。
- ステータス表記が仕様書と一致しているか。
- 選択できる並び順が実際に動作するか。
- 期限切れチケットの色が仕様書どおりか。

仕様書と実装に差分があっても、どちらが正しいかは自動的に決まりません。根拠を記録し、勝手に仕様を決めず、担当者へ確認してください。
