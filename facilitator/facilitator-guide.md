# 講師進行ガイド

## 事前準備

- 受講者がNode.js 20.12.0以上、Git、VS Code、GitHub Copilot Chatを利用できることを確認する。
- `npm ci`、`npm test`、`npm run app`、`npm run slides`を事前に確認する。
- Dashboardに12件表示されることを確認する。
- 機密情報、認証情報、個人情報、未公開の顧客情報をプロンプトへ入力しない注意を冒頭で伝える。

## 60分進行

| Session | 時間 | 講師の重点 |
| --- | ---: | --- |
| Overview | 5 min | ゴール、12件表示、テスト成功、人が検証する原則 |
| S1 | 5 min | 対象・目的・制約・出力形式を含む最初の依頼 |
| S2 | 15 min | Copilotの説明を実ファイルと照合する |
| S3 | 15 min | 仕様と実装の差分を断定せず、要確認事項へ分ける |
| S4 | 15 min | 変更前確認、小さな編集、差分、再テスト |
| S5 | 5 min | 明日試す作業と人が確認する項目を言語化する |

## 省略しない確認

- 時間が押しても、S4の変更前後の`npm test`と差分確認を省略しない。
- Copilotが存在しない関数や根拠のない仕様を示した場合は、誤りを教材として扱い、実ファイルへ戻る。
- 仕様書と実装が異なる場合、どちらが正しいかをCopilotだけで決めない。
- `internalMemo`の具体値は画面、チャット、発表資料へ出さない。
